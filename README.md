# 🧠 CodeMentor AI

> An AI-powered coding mentor that helps beginners understand code, debug errors, practice programming, and learn through an interactive AI assistant.

CodeMentor AI is a modern web application designed to make programming easier for beginners. Instead of simply giving answers, it helps users understand their code, identify mistakes, learn programming concepts, and improve their problem-solving skills.

## ✨ Features

### 🤖 AI Code Explainer

Paste your code and let AI explain it in simple, beginner-friendly language.

**What it provides:**
- Code explanation
- Programming concepts
- Logic breakdown
- Beginner-friendly guidance
- Learning tips

---

### 🐛 AI Code Debugger

Find and understand problems in your code with AI assistance.

**What it provides:**
- Error detection
- Explanation of why the error occurs
- Corrected code
- Important programming concepts
- Mentor tips

---

### 🧠 Coding Practice

Practice programming problems and receive AI-powered feedback.

Users can:
- Select programming languages
- Choose coding problems
- Submit solutions
- Receive AI feedback
- Understand mistakes
- Improve their coding skills

---

### 💬 AI Coding Mentor

Ask programming-related questions and interact with an AI mentor.

The mentor can help with:
- Programming concepts
- Syntax questions
- Debugging
- Learning guidance
- Coding doubts
- Beginner-friendly explanations

---

### 📊 Learning Dashboard

The dashboard provides a centralized view of the learner's activity.

It includes:
- Learning progress
- Coding activity
- Problems solved
- Code explanations
- Debugging activity
- Learning streak
- Recent activity

---

### 🔥 Learning Streak

CodeMentor AI tracks learning activity using browser storage and encourages consistent practice through a daily learning streak.
